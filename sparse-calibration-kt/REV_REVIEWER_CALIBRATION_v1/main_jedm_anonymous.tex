\begin{abstract}
Knowledge Tracing (KT) models are typically evaluated with aggregate predictive metrics such as the area under the ROC curve (AUC) and accuracy. These metrics can mask how a model behaves on sparse and cold-start Knowledge Components (KCs)---concepts with limited or no training-fold evidence---even though educational decision support often depends on the reliability of predicted probabilities. Rather than proposing a new model, we treat KT evaluation as a reproducibility and diagnostic problem. We present a diagnostic protocol that combines learner-based and temporal splits, train-only KC-frequency stratification with an explicit strict cold-start group, per-stratum calibration analysis via Expected Calibration Error (ECE), Brier-score decomposition, and reliability diagrams, sample-size-aware reporting, and an operational leakage and predictive-sanity workflow (L1--L8). We instantiate the protocol on ASSISTments 2012, Junyi Academy, and XES3G5M with IRT, DKT, and SimpleKT. Sparse training evidence does not universally degrade discrimination, but it can expose dataset-dependent calibration vulnerability. On ASSISTments 2012, SimpleKT ECE rises from $0.114$ on dense KCs to $0.228$ on sparse KCs (Limited flag, $N=415$); other datasets show flat or inverted stratum patterns. On one learner-based fold of that dataset, a global threshold $\tau=0.7$ yields higher SimpleKT false mastery among advances on sparse than on dense KCs (Limited flag); the SimpleKT $\Delta\mathrm{FM}$ stays positive on all five training seeds (mean $0.047$; four unique partitions). A train-only GKT graph shrinks the seed-42 gap. That calculation is a simulated gate, not a classroom trial. A controlled reduction of training rows for the same originally dense KCs increases within-KC ECE only in some dataset--model cells. We characterize the conditions associated with this vulnerability---sparse mass, evaluation support, and frequency--difficulty coupling---and provide reproducible diagnostics for identifying when it matters. Occupancy reporting remains useful even when the empirical priority of sparse-stratum claims is low. Channel L8 additionally flagged a prediction--label misalignment that aggregate metrics alone would not reveal. We provide an anonymized reproducibility artifact for peer review and will release the public version upon acceptance.
\end{abstract}

\section*{Artifact Availability \& Reproducibility Checklist}
\begin{sloppypar}
The anonymized code, data preprocessing scripts, and reproducible evaluation pipelines are available for peer review at \url{https://anonymous.4open.science/r/Sparse-Concept-and-Calibration-6E5B/}. The public repository will be released upon acceptance. Consistent with the design principles of Section~\ref{sec:protocol}, the artifact includes the following standardized components:
\end{sloppypar}
\begin{itemize}
  \item \textbf{Dataset Preprocessing:} Scripts that normalize raw data into the schema defined in Section~\ref{sec:protocol}.
  \item \textbf{Split Construction:} Reproducible partition logs and multi‑seed split constructors.
  \item \textbf{Prediction‑level Exports:} CSV files containing baseline predicted probabilities and ground‑truth labels.
  \item \textbf{KC‑Strata Assignment:} Code mapping training‑fold frequencies to strata buckets.
  \item \textbf{Calibration Verification:} Scripts computing Expected Calibration Error (ECE).
  \item \textbf{Brier Decomposition:} Implementation of Uncertainty, Reliability, and Resolution equations.
  \item \textbf{Reliability Diagrams:} Plotting utilities for multi‑strata calibration curves.
  \item \textbf{Leakage \& Predictive-Sanity Workflow:} Automated logs for the L1--L8 operational checklist, including the L8 warm-cohort sanity check.
  \item \textbf{LaTeX Table Exporters:} Python exporters generating book‑tabs tables.
  \item \textbf{One‑Command Reproduction:} Unified script ensuring machine‑independent reproducibility.
\end{itemize}
